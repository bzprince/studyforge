# StudyForge

An AI study planner. Add your exam date and subjects, get a schedule with extra time on weak areas, plus a focus timer.

> **Demo version.** This is an early demo built to show the idea and the interface. It is not a finished product, and results are for demonstration only.

**Live demo:** https://studyforgebd.netlify.app/

## What it does
- Enter your **exam date** and **subjects**
- Get a **study schedule** with extra time on weak areas
- Stay on track with a built-in **focus timer**

## Built with
HTML · CSS · JavaScript

Demo / work in progress. Features may be incomplete and can change.
